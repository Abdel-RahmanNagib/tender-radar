# رادار المناقصات الاستشارية

يفحص مصادر المناقصات كل ساعة (24 ساعة × 7 أيام) ويرسل إشعاراً على الموبايل والكمبيوتر لكل مشروع استشاري جديد يناسب تخصصات المكتب: تصريف الأمطار والسيول، الهيدرولوجيا، الصرف الصحي، شبكات المياه والري، الطرق والرصف والتسوية، والمرافق والبنية التحتية.

**الدول:** مصر، ليبيا، سوريا، الأردن، فلسطين، السعودية، الإمارات، قطر، الكويت، البحرين، عُمان، اليمن، العراق، والمشاريع الإقليمية.

**المصادر:** البنك الدولي، منصة اعتماد (السعودية)، مجلس المناقصات (عُمان)، مجلس المناقصات والمزايدات (البحرين)، بوابات الإمارات (المنصة الرقمية الاتحادية، eSupply حكومة دبي، بوابة أبوظبي ADGPG، هيئة كهرباء ومياه دبي)، منصة مناقصات (قطر)، البنك الأوروبي لإعادة الإعمار EBRD (مصر والأردن وفلسطين)، بوابة مشتريات الأمم المتحدة UNGM، البنك الإسلامي للتنمية، وأخبار الطروحات.

لكل فرصة يعرض التطبيق:
- **البيانات:** الجهة، الرقم المرجعي، نوع الإعلان، المواعيد، قيمة الكراسة، والتمويل.
- **الأوراق المطلوبة:** قائمة تحددون منها ما تم تجهيزه، مع شروط الإعلان نفسه.
- **التواصل:** أرقام وإيميلات جهة الاستفسار بأزرار اتصال وواتساب، وإيميل استفسار جاهز.
- **خطوات التقديم:** بالترتيب، وكل خطوة بتاريخها.

## التشغيل

افتح **`START-HERE.html`** (أو `app/guide.html`) للدليل الكامل خطوة بخطوة. باختصار:

1. ارفع كل ملفات هذا المجلد إلى مستودع **Public** جديد على GitHub.
2. `Settings` ← `Pages` ← Source: **GitHub Actions**.
3. `Settings` ← `Secrets and variables` ← `Actions` ← سرّ جديد باسم `NTFY_TOPIC` وقيمته اسم قناة صعب التخمين.
4. `Actions` ← `Tender Radar` ← `Run workflow`.
5. افتح `https://اسم-حسابك.github.io/اسم-المستودع/` وثبّته على الموبايل والكمبيوتر.
6. ثبّت تطبيق **ntfy** واشترك في نفس اسم القناة لتصلك الإشعارات.

بدون GitHub: `RUN-ON-PC.bat` على كمبيوتر ويندوز مثبت عليه Python. للتجربة ببيانات مثال: `TRY-DEMO.bat`.

## مساعد كمبيوتر المكتب (قطر وعُمان)

منصة مناقصات قطر ترفض السيرفرات السحابية (ومنها GitHub)، ومجلس المناقصات العُماني لا يعطيها إلا أحدث 50 مناقصة، لكنهما يفتحان كاملين من شبكة المكتب. (موقع الجهاز المركزي للمناقصات بالكويت يمنع أي فحص آلي، فيُراجع يدوياً من رابطه.)
مجلد `pc-helper/` فيه مساعد صغير يُثبَّت مرة واحدة على كمبيوتر المكتب (`INSTALL-PC-HELPER.bat`) ويستخدم Python الموجود مع QGIS.
يفحص البوابتين كل ساعة والجهاز شغال، ويرسل النتائج **موقّعة** عبر قناة ntfy خاصة، فيتحقق الفحص السحابي من التوقيع
بالمفتاح العام `scanner/pc_public_key.txt` قبل إضافتها للتطبيق. المفتاح الخاص يبقى على الكمبيوتر فقط.

## الملفات

| المسار | المحتوى |
|---|---|
| `app/` | التطبيق (يُنشر كموقع ويُثبت على الأجهزة) و`app/data` نتائج الفحص |
| `scanner/settings.json` | الإعدادات البسيطة (الدول، مستوى المناسبة، الإشعارات في وضع الكمبيوتر) |
| `scanner/profile.json` | التخصصات والكلمات المفتاحية ومصادر البحث |
| `scanner/run.py` | محرك الفحص |
| `.github/workflows/radar.yml` | التشغيل التلقائي كل ساعة على GitHub |

اختبار بدون إنترنت: `python scanner/tests/test_scanner.py`
