رادار المناقصات فتح التطبيق

طريقة تشغيل رادار المناقصات

البرنامج جزءان: الرادار يفحص مصادر المناقصات كل ساعة ويرسل إشعاراً بكل فرصة مناسبة، والتطبيق تفتحه على الموبايل أو الكمبيوتر لترى الأوراق المطلوبة وجهات التواصل وخطوات التقديم لكل فرصة.

الطريقة الموصى بها تشغيلهما مجاناً على GitHub، فيعملان 24 ساعة طوال الأسبوع حتى والكمبيوتر مغلق. الإعداد مرة واحدة، حوالي 15 دقيقة، ولا يحتاج أي برمجة.

التشغيل السحابي (موصى به)

أسماء الأزرار في GitHub بالإنجليزية، فكتبناها كما تظهر.

  1. 1
    أنشئ حساباً مجانياً

    من github.com/signup.

  2. 2
    أنشئ مستودعاً جديداً

    الزر + أعلى الصفحة ← New repository ← الاسم tender-radar ← اختر Public ← Create repository.

    • يجب أن يكون Public لأن استضافة التطبيق مجانية للمستودعات العامة فقط. المنشور فيه إعلانات مناقصات عامة أصلاً، وسجل مشاريعكم لا يُرفع إليه (يبقى على أجهزتكم). الإيميلات وكلمات المرور تُحفظ كأسرار مخفية.
  3. 3
    ارفع ملفات البرنامج

    فك ضغط الملف ← في صفحة المستودع اضغط uploading an existing file ← اسحب كل محتويات مجلد TenderRadar (بما فيها المجلد .github) ← Commit changes.

    • تأكد أن الملف .github/workflows/radar.yml ظهر في المستودع. لو لم يظهر: Add file ← Create new file ← اكتب الاسم .github/workflows/radar.yml ← الصق محتوى الملف من المجلد ← Commit changes.
  4. 4
    فعّل استضافة التطبيق

    Settings ← Pages ← في Source اختر GitHub Actions.

  5. 5
    اختر اسم قناة الإشعارات واحفظه كسرّ

    Settings ← Secrets and variables ← Actions ← New repository secret ← Name: NTFY_TOPIC ← Secret: اسم صعب التخمين مثل delta-radar-7k3m9q ← Add secret.

    • احتفظ بالاسم؛ ستكتبه في الموبايل في الخطوة 9. من يعرف الاسم يستقبل الإشعارات، فلا تجعله سهلاً.
  6. 6
    شغّل أول فحص

    تبويب Actions ← Tender Radar ← Run workflow ← Run workflow. انتظر 3–5 دقائق حتى تظهر العلامة الخضراء. بعدها يعمل وحده كل ساعة.

    • لو طلب GitHub تفعيل Actions اضغط I understand my workflows, go ahead and enable them.
  7. 7
    افتح التطبيق

    الرابط: https://اسم-حسابك.github.io/tender-radar/ — ويظهر أيضاً في Settings ← Pages. أرسله لزملائك.

  8. 8
    ثبّت التطبيق على أجهزتكم
    • أندرويد – تطبيق كامل: من الموبايل افتح TenderRadar.apk ← بعد التحميل اضغط على الملف ← «تثبيت». أول مرة يطلب أندرويد السماح بالتثبيت من المتصفح: «الإعدادات» ← «السماح من هذا المصدر» ثم ارجع واضغط «تثبيت». افتح التطبيق واضغط «سماح» للإشعارات؛ بعدها يفحص كل ساعة ويرسل إشعاراً بكل فرصة جديدة، بدون ntfy.
    • آيفون: افتح الرابط من Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية». يظهر بأيقونته ويفتح كتطبيق مستقل. آبل لا تسمح بتثبيت تطبيقات من خارج App Store بدون حساب مطوّر مدفوع، لذلك إشعارات الآيفون تصل عبر تطبيق ntfy المجاني (الخطوة 9).
    • أندرويد بدون ملف: افتح الرابط من Chrome ← القائمة ⋮ ← «تثبيت التطبيق».
    • الكمبيوتر: افتح الرابط من Chrome أو Edge ← أيقونة التثبيت في آخر شريط العنوان.
  9. 9
    فعّل الإشعارات
    • الموبايل: ثبّت تطبيق ntfy المجاني (أندرويد – آيفون) ← + ← اكتب نفس اسم القناة ← Subscribe.
    • الكمبيوتر: افتح ntfy.sh/app ← Subscribe to topic ← نفس الاسم ← اسمح بالإشعارات.
    • أو من داخل التطبيق: الإعدادات ← الإشعارات ← اكتب الاسم ← «اشترك الآن».
    • كل زميل يشترك بنفس الاسم تصله نفس الإشعارات.

مناقصات البوابات التي تراسل الموردين المسجّلين فقط

أدنوك وقطار الاتحاد وهيئة كهرباء الشارقة (SEWA) والاتحاد للماء والكهرباء على SAP Ariba، ودائرة المالية في الشارقة، ومنصة توريد في عجمان، ورأس الخيمة على Coupa، ووزارة الطاقة والبنية التحتية: لا تنشر أغلب مناقصاتها للعامة، وترسلها بالإيميل للموردين المسجّلين في التخصص.

  1. سجّلوا المكتب كمورد/استشاري في كل بوابة (مرة واحدة) باختيار تخصصات الاستشارات الهندسية والبنية التحتية، وبإيميل واحد للشركة.
  2. في إيميل الشركة اعمل قاعدة تحويل تلقائي لرسائل هذه البوابات إلى العنوان المكتوب في الملف EMAIL-FORWARD-ADDRESS.txt داخل مجلد مساعد كمبيوتر المكتب (عنوان خاص بمكتبكم، لا تنشروه).
  3. مساعد الكمبيوتر يقرأ الرسائل المحوّلة كل ساعة، ويحوّل كل دعوة لفرصة في التطبيق وإشعار، مع حذف أسماء المستخدمين وروابط الدخول الشخصية. رسائل كلمات المرور والفواتير تُتجاهل.

ماذا يحدث بعد ذلك

  • أول فحص يسجل كل الفرص المفتوحة حالياً ويرسل رسالة واحدة ملخصة، حتى لا تصلك عشرات الرسائل مرة واحدة.
  • بعدها تصلك رسالة لكل فرصة جديدة فيها: الدولة، الجهة، آخر موعد وعدد الأيام الباقية، التخصص، وإيميل أو رقم جهة الاستفسار. الضغط على الإشعار يفتح الفرصة في التطبيق.
  • كل صباح الساعة 8 بتوقيت القاهرة يصل ملخص يومي بعدد الفرص المفتوحة وأقرب المواعيد، وهو أيضاً تأكيد أن الرادار يعمل.

ماذا تجد في التطبيق لكل فرصة

البيانات

الجهة، الرقم المرجعي، نوع الإعلان، طريقة الاختيار، التمويل، قيمة الكراسة، الضمان، والمواعيد المهمة مع زر لإضافتها إلى التقويم.

الأوراق المطلوبة

قائمة تحددون منها ما تم تجهيزه، مع تمييز ما ذكره الإعلان نفسه، وشروط القائمة المختصرة من نص الإعلان، ومشاريعكم المشابهة من سجل المشاريع.

التواصل

اسم الجهة والشخص، أزرار اتصال وواتساب وإيميل، وإيميل استفسار جاهز بالعربي أو الإنجليزي، وأرقام الدعم الفني الرسمية للبوابة.

خطوات التقديم

الخطوات بالترتيب، وكل خطوة بتاريخها المحسوب من مواعيد الإعلان، وتحددون ما تم إنجازه.

الشريط المقسّم تحت كل فرصة يمثل المدة من النشر حتى آخر موعد مثل مقياس الرسم في اللوحات: كل قطعة أسبوع، والجزء الداكن ما مضى، ويتحول للأصفر قبل الموعد بأسبوع وللأحمر قبله بثلاثة أيام.

التشغيل على كمبيوتر المكتب (بدون GitHub)

  1. ثبّت Python من python.org وفعّل خيار Add Python to PATH أثناء التثبيت.
  2. افتح الملف scanner/settings.json بالمفكرة واكتب اسم القناة بجانب ntfy_topic.
  3. اضغط مرتين على RUN-ON-PC.bat: يفتح التطبيق على http://localhost:8765 ويفحص كل ساعة طالما النافذة مفتوحة.
  4. للتشغيل تلقائياً عند فتح الكمبيوتر اضغط مرتين على INSTALL-AUTOSTART.bat.
  5. للتجربة ببيانات مثال بدون إنترنت: TRY-DEMO.bat.

في هذا الوضع يفتح التطبيق على هذا الكمبيوتر فقط، والموبايل يستقبل الإشعارات عبر ntfy مع رابط الإعلان الرسمي.

إشعارات إضافية (اختياري)

  • تيليجرام: أنشئ بوتاً من @BotFather وضع الرمز في سرّ باسم TELEGRAM_BOT_TOKEN. أي شخص يضغط Start على البوت يشترك تلقائياً، ويوقفها بإرسال /stop.
  • الإيميل: أضف أسراراً بأسماء SMTP_HOST (مثل smtp.hostinger.com أو smtp.gmail.com) وSMTP_PORT (465) وSMTP_USERNAME وSMTP_PASSWORD وEMAIL_TO (أكثر من إيميل بينها فاصلة).

حل المشاكل

لا تصل الإشعارات
تأكد أن اسم القناة في سرّ NTFY_TOPIC مطابق حرفياً للاسم في تطبيق ntfy. في التطبيق: الإعدادات ← حالة الرادار ← «قنوات الإشعار المفعّلة».
التطبيق يقول «الفحص متأخر»
افتح Actions وتأكد أن آخر تشغيل نجح. قد يؤخر GitHub التشغيل المجدول قليلاً وقت الضغط، وقد يوقف الجدولة إذا توقف نشاط المستودع طويلاً؛ الرادار يحفظ نتائجه كل ساعة فلا يحدث ذلك عادةً، وإن حدث اضغط Enable workflow.
مصدر يظهر «تعذر الوصول»
بعض البوابات الحكومية تحجب الطلبات الآلية أو تحتاج تسجيل دخول. باقي المصادر تستمر بشكل طبيعي.
أريد فرصاً أكثر أو أقل
في scanner/settings.json غيّر min_level إلى high (المناسب جداً فقط) أو medium (الافتراضي) أو low (فرص أكثر).
أريد إضافة كلمة أو تخصص أو دولة
في scanner/profile.json: التخصصات وكلماتها بالعربي والإنجليزي، والدول وأسماء مدنها.

البيانات مأخوذة آلياً من المصادر الرسمية والأخبار المنشورة. راجعوا الإعلان الرسمي دائماً قبل التقديم.
